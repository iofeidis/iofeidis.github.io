# Iason Ofeidis — Personal Academic Website

Built with the [Hugo Blox Academic CV](https://hugoblox.com/templates/academic-cv) template.

## Local preview

```bash
pnpm install   # or: npm install
hugo server
```

Then open http://localhost:1313

## Deploy

GitHub Actions builds and deploys to GitHub Pages from `master` (configured after you approve going live).

## Backup of previous site

The previous Jekyll Academic Pages site is preserved on branch `backup/jekyll-academic-pages`.
